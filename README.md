### 📅 Calendar Invitation Automation — Organization-Wide Summary

A reusable **Google Apps Script tool** that allows START-DOST departments to send Google Calendar invitations to participants listed in a **Google Sheet**.

**What it does:**
- Automatically detects the **active/selected sheet** containing participant data.
- Identifies participants' **email addresses** from the spreadsheet.
- Provides a **user-friendly modal** where users can configure:
  - Event title
  - Event date
  - Start and end time
  - Calendar to use
  - Calendar description
- Shows an **event preview** before sending.
- Creates **one Google Calendar event** and adds all eligible participants as guests.
- Sends calendar invitations/notifications to participants.
- Can be **reused across different departments, events, and spreadsheets** without modifying the core script.

**In short:**  
> **Google Sheet → Calendar Invitation Tool → Configure Event → Preview → Send Invitations**

This makes it useful for **workshops, orientations, meetings, trainings, recruitment activities, and other department events** where participant information is maintained in a spreadsheet.
